Rudy

The little black robot who walks the WalkingLine, cut loose from the browser.

One file. No installer, no runtime, no background service. He draws himself on top of other windows, walks back and forth in 60 seconds per crossing, and never touches the network, the registry or your files. Click him to pause, double-click to quit.

Windows 10 / 11

Download Rudy.exe 79 KB · .NET Framework 4.8, already part of Windows
Windows may call it suspicious. The build is unsigned — a code-signing certificate costs money and this is a free toy — so SmartScreen and browsers treat a 79 KB executable nobody has downloaded before with suspicion. Nothing is wrong with the file, and you do not have to take my word for it: the full source is on GitHub, or you can build it yourself in ten seconds (below).
  1. Chrome: the download bubble says the file was blocked or is suspicious — open Ctrl+J, find Rudy.exe, click the arrow next to it and choose Keep.
  2. Edge: in the Downloads panel, open the ··· menu on Rudy.exe and choose Keep.
  3. On first run Windows may show Windows protected your PC — click More info, then Run anyway.

Build it yourself

The C# compiler ships inside Windows, so there is no SDK to install. Clone the repository and run one script:

git clone https://github.com/gouwylieven/portfolio.git
cd portfolio
powershell -ExecutionPolicy Bypass -File rudy-desktop\win\build.ps1

Then run rudy-desktop\dist\Rudy.exe. A locally compiled copy carries no download mark, so none of the warnings above appear.

macOS 11+

There is no prebuilt .app, because the bundle is built and ad-hoc signed by Xcode's compiler on your machine. With the Xcode Command Line Tools installed:

git clone https://github.com/gouwylieven/portfolio.git
cd portfolio/rudy-desktop/mac
./build.sh

That produces dist/Rudy.app.

What he never does

  • No network access of any kind — no sockets, no telemetry, no update check.
  • No files read or written except his own embedded sprite.
  • No registry keys, login items or startup entries; no admin rights.
  • No keystroke hooks, no window inspection, no screen recording.
  • Nothing left running after you quit him.
